# Instruções para agentes de IA

Antes de mudar qualquer coisa:

1. Leia **[docs/PROJETO.md](docs/PROJETO.md)** (como o projeto é feito e o padrão do código) e
   **[docs/BANCO.md](docs/BANCO.md)** (como o banco SQLite está feito e como mudá-lo sem quebrar a produção).
2. Siga o fluxo da seção **"Para assistentes de IA"** do [README.md](README.md):
   branch própria a partir do `main`, `npm run build` sem erros, **um PR para o `main` com a versão final das alterações**,
   sem push direto no `main`, sem merge e sem publicar nada no servidor.
